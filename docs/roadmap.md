# Cockpit roadmap

Cockpit now includes the first complete set of local development tools. Future work can improve coverage and customization.

## Current

- Search and open supported local projects
- Open projects in installed editors and terminals
- Review Git branches and working tree counts
- View Docker Compose services and logs
- Start or stop Compose services after confirmation
- Inspect listening ports and stop processes after confirmation
- Open each tool from the Cockpit home screen

## Next

- Add more project detectors
- Make Codex and Claude Code paths configurable
- Add Docker service filtering
- Improve links between listening ports and discovered projects
- Add preferences for hidden tools and application order
