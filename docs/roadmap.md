# Cockpit Roadmap

## Current

- Discover Next.js, Django, Python, and Docker Compose projects.
- Open projects in VS Code, Terminal, Codex, Claude Code, Finder, and GitHub.
- Copy development and Docker commands for review before running them.

## Next

- Add a Cockpit home screen for selecting small tools.
- Add Git details and common repository actions.
- Add Docker container controls.
- Add local server and port discovery.

Each tool should remain useful on its own and must avoid running destructive commands without confirmation.
