# Cockpit: نظرة عامة مؤكدة

مرجع الفحص المحلي: `c47c3388e46b103adda0b2951061b1e021c8a321` على الفرع `codex/developer-command-center`.

- Cockpit إضافة Raycast لمطور يتابع مشاريعه المحلية على macOS من لوحة واحدة.
- تجمع اللوحة أعداد المشاريع ومستودعات Git وخدمات Docker والعمليات التي تستمع على منافذ، ثم تفتح تفاصيلها.
- اكتشاف المشاريع يقرأ المجلدات المباشرة تحت المسار المختار، ويتعرف على Next.js وDjango وPython وDocker Compose.
- أدوات Git داخل المنتج للقراءة فقط. إجراءات تشغيل/إيقاف Docker وإيقاف عملية تتطلب تأكيدًا في الواجهة.
- المشروع TypeScript/React مع واجهات Raycast واختبارات Vitest.
