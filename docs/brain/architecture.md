# Cockpit: خريطة الكود والبنية

المصدر هو نسخة Git المحلية عند `c47c3388e46b103adda0b2951061b1e021c8a321`.

```text
أمر Raycast -> إعداد مسار المشاريع -> ملخص اللوحة
  -> اكتشاف المشاريع وقراءة Git وDocker والمنافذ
  -> عرض تفاصيل المجال والإجراءات المسموحة
```

الاستدعاءات الخارجية تستخدم `execFile` ومصفوفات معاملات. قراءة المنافذ تستخدم `lsof`،
وقراءة Docker تفحص مسارات تثبيت macOS المعروفة. لا ينبغي أن تتحول ذاكرة المشروع إلى صلاحية لإيقاف خدمة.

## قواعد العمل ذات الصلة

- حافظ على قراءة Git فقط داخل المنتج، وعلى تأكيد أفعال Docker وإيقاف العمليات.
- لا تقرأ محتويات `.env` لبناء ملخص أو عدّاد.
- البناء والاختبارات المعرّفة في `package.json` هي `npm test` و`npm run lint` و`npm run build`؛
  ذكر الأوامر هنا ليس ادعاء بأنها نُفّذت.
